# Generated reporting outputs

Rendered figures are written under `results/paper/figures/`. Machine-readable source tables are written under `results/analysis/figure_data/` or the corresponding RQ-specific analysis directory.

```text
studies/overtopping/analysis/stage06_competence_vs_overtopping_figures.py
```

## RQ4 outputs

Pythia checkpoint files:

```text
results/paper/figures/05_rq4_learning/
├── fig5a_pythia_checkpoint_trajectory.pdf
├── fig5s1_pythia_checkpoint_U_0to1.pdf
└── fig5s2_pythia_checkpoint_U_1to0.pdf
```

Poisoning-derived outputs are written under:

```text
results/paper/figures/05_rq4_learning/poisoning/
```

Per-run poisoning renderings can include:

```text
01_clean_vs_poisoned_overtopping_development.pdf
02_channel_role_reassignment.pdf
03_prospective_defense_leverage.pdf
03b_clean_reference_defense_interpretation.pdf
03c_one_checkpoint_ahead_defense_interpretation.pdf
04_clean_vs_poisoned_checkpoint_overtopping.pdf
```

The stable Grammar clean-reference defense figure is aggregated across compatible
training seeds with seed as the replicate unit. Its default summary is the
across-seed median with Q1-Q3 uncertainty:

```text
results/paper/figures/05_rq4_learning/rq4_grammar_clean_reference_defense.pdf
```

The seed-level and aggregated checkpoint/budget tables are written under
`results/analysis/rq4_learning/poisoning/cross_seed_tables/`.

Poisoning source tables and availability conditions are defined in [Poisoning outputs](../experiments/poisoning/outputs.md).

## Output provenance

Rendered outputs are generated from deterministic analysis products or machine-readable source tables. Their analysis population and metric availability are recorded in the corresponding analysis outputs and reproducibility audits.
